# Changelog: Aplicação de Dados Reais do Evento

**Data:** 19/05/2026
**Hora:** 15:39

## Motivação
**Prompt:** Aplique os dados reais do evento (links, whatsapp, data, e remoção da sessão de filtro do Instagram).

## Modificações
- **Botão "Vocês Aceitam?"**: Transformado em um link direto com a URI do WhatsApp configurada para enviar a mensagem: "Olá! Confirmamos com muita alegria que seremos padrinhos deste momento único!" para o número `+55 31 9839-6857`.
- **Data e Horário**: Atualizados de *21 de Fevereiro* para *12 de Setembro, às 15h30*. O aviso de atraso no rodapé foi atualizado para sugerir a chegada às *15h*.
- **Local (Cerimônia/Recepção)**: Como ambos os eventos ocorrerão no mesmo lugar, a sessão HTML que dividia dois locais foi fundida em uma única caixa de texto informando o endereço "Sítio São José / Sítio Santa Rita" em Ribeirão das Neves.
- **Action Buttons (Links)**:
  - Botão de LOCAL agora direciona para o link do Google Maps fornecido.
  - Botão de RECEPÇÃO foi alterado para confirmar "PRESENÇA" apontando para o Google Forms.
  - Botão de PRESENTES recebeu o link do design do Canva.
- **Sessão "Moldura dos Noivos"**: Todo o container da sessão de fotos para o Instagram e a área de "filtros" foram apagados, pois a funcionalidade foi descartada pelos noivos. O bloco de texto de alerta para evitar atrasos foi preservado na sessão de encerramento do convite.
- **Nome no Rodapé**: Corrigido de "Isabela e Marcos" (placeholder antigo) para "Bruna e Vitor".
